# 平台连续劳务报酬个税计算器

一款专业的在线个税计算工具，专门用于计算平台连续劳务报酬（如直播打赏、外卖配送、网约车等）的个人所得税，支持**旧政策生产经营所得**和**新政策累计预扣法**自动切换。

## 功能特点

### 📅 多月累计
- 采用12个月份网格布局，输入便捷
- 支持税前→税后、税后→税前双向互算
- 支持指定计算年份
- 自动跳过空月份（未输入金额的月份）
- 支持"断月重置"功能：相邻月份中断超过1个月时自动归零重新起算
- 自动识别跨年重置，每年1月自动重置累计数据
- **智能政策识别**：自动根据月份判断适用政策（2025年10月1日前/后）
- 支持导出计算结果为 CSV 文件

### 📁 批量计算
- 支持上传 CSV、Excel 文件批量处理
- **智能列映射**：自动识别表格列类型（姓名、月份、金额、身份证号、电话、银行卡号、备注）
- 支持手动调整列映射，可视化预览每列数据
- 支持"金额类型"选择：税前收入（累计预扣）或税后收入（反算）
- 兼容多种月份格式：2024-01、2024/01、2024年1月、202401、Excel日期序列号等
- 自动处理 GBK 和 UTF-8 编码
- 支持分批上传、累加计算
- 支持"断月重置"功能
- **智能政策识别**：自动根据每行数据的月份判断适用政策
- 导出结果包含政策类型标识

## 计税规则

### 政策切换
- **2025年10月1日及之后**：适用新政策（连续劳务，累计预扣法）
- **2025年9月及之前**：适用旧政策（生产经营所得，不扣税）

### 新政策：累计预扣法
依据国家税务总局公告2018年第61号：

| 累计应纳税所得额 | 税率 | 速算扣除数 |
|---------------|------|----------|
| ≤36,000 | 3% | 0 |
| ≤144,000 | 10% | 2,520 |
| ≤300,000 | 20% | 16,920 |
| ≤420,000 | 25% | 31,920 |
| ≤660,000 | 30% | 52,920 |
| ≤960,000 | 35% | 85,920 |
| >960,000 | 45% | 181,920 |

#### 计算公式
- **预扣收入额** = 每次劳务报酬收入 × 80%
- **累计预扣税额** = (累计预扣收入额 - 累计减除费用) × 适用税率 - 速算扣除数
- **累计减除费用** = 5,000元/月 × 累计月份数

### 旧政策：生产经营所得
- 2025年10月1日之前的收入不扣税
- 税前收入 = 税后收入

### 跨年与断月规则
- **跨年重置**：每年1月起，累计收入、累计已预扣税额、累计减除费用均归零重新起算
- **断月重置**：开启后，相邻月份如果中断超过1个月，累计自动归零重新起算
- **政策切换**：跨2025年10月时，累计会自动重置以适配新政策

## 使用技术

- 暗色主题界面
