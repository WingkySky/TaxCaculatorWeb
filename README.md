# 平台连续劳务报酬个税计算器

一款专业的在线个税计算工具，专门用于计算平台连续劳务报酬（如直播打赏、外卖配送、网约车等）的个人所得税，采用国家税务总局规定的**累计预扣法**。

## 功能特点

### 🧮 单笔计算
- 支持税前→税后、税后→税前双向互算
- 可设置本年累计月数和累计预扣收入额
- 实时显示预扣税额和实际税负率

### 📅 多月累计
- 按月录入收入，系统自动逐月计算
- 自动识别年度边界，每年1月自动重置
- 支持"断月重置"功能：相邻月份中断超过1个月时自动归零
- 支持导出计算结果为 CSV 文件

### 📁 批量计算
- 支持上传 CSV、Excel 文件批量处理
- 自动识别人员（支持身份证号、电话、银行卡号）
- 兼容多种月份格式：2024-01、2024/01、2024年1月、202401、Excel日期序列号等
- 自动处理 GBK 和 UTF-8 编码
- 支持分批上传、累加计算

## 计税规则

依据国家税务总局公告2018年第61号：

| 累计应纳税所得额 | 税率 | 速算扣除数 |
|---------------|------|----------|
| ≤36,000 | 3% | 0 |
| ≤144,000 | 10% | 2,520 |
| ≤300,000 | 20% | 16,920 |
| ≤420,000 | 25% | 31,920 |
| ≤660,000 | 30% | 52,920 |
| ≤960,000 | 35% | 85,920 |
| >960,000 | 45% | 181,920 |

### 计算公式
- **预扣收入额** = 每次劳务报酬收入 × 80%
- **累计预扣税额** = (累计预扣收入额 - 累计减除费用) × 适用税率 - 速算扣除数
- **累计减除费用** = 5,000元/月 × 累计月份数

## 使用技术

- 纯前端实现，无需后端服务
- 支持 SheetJS (xlsx) 库处理 Excel 文件
- 响应式设计，适配桌面和移动端
- 支持暗色主题

## 本地使用

直接在浏览器中打开 `tax-calculator.html` 文件即可使用，无需安装任何依赖。
