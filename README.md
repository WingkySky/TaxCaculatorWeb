# 个税计算器 · 劳务报酬 / 工资薪金

一款专业的在线个税计算工具，支持两大所得类型：

- **平台连续劳务报酬**（如直播打赏、外卖配送、网约车等）——支持**旧政策生产经营所得**和**新政策累计预扣法**自动切换
- **工资薪金**——按累计预扣法计算三险一金、专项附加扣除与个税，支持应发↔实发双向互算

两种类型均支持「多月累计」手工计算与「批量计算」表格上传。

## 功能特点

### 💰 所得类型切换
- 页面顶部一键切换「劳务报酬」/「工资薪金」，两个页签共用该选择
- 切换时自动联动说明文案、输入提示、断月开关显隐与批量列识别

### 🏙️ 城市社保公积金政策库（工资薪金）
- 内置 12 个主要城市（北上广深杭宁苏成渝汉西津）+ 自定义，**分险种**维护个人比例与基数上下限（养老/医疗/失业/公积金各自独立）
- **政策数据外置在 `tax-policy-data.js`**，与页面同目录自动加载（拷贝该文件即可跨机使用）；文件缺失时仅保留"自定义"城市并提示
- **三层持久化**：`tax-policy-data.js` 出厂种子 → 本机浏览器自动存档（弹层编辑/导入后即时保存，刷新自动加载）→ Excel / JSON 导出备份。弹层可一键"恢复数据文件默认"；本机存档不跨浏览器/电脑，清除浏览器数据会丢失，跨机请导出 Excel/JSON
- 多年度政策记录（含生效月区间，兼容广州/深圳 7 月~次年 6 月社保年度），按工资月份**自动匹配年度**，也可手动固定
- 公积金比例按城市可选档位（5%~12%）择档；**公积金月缴存额四舍五入取整到元**，社保保留到分
- 「政策数据管理」弹层：查看/编辑政策数据、新增城市与年度、整库 **Excel 导入/导出**（扁平表格，适合人工维护）与 JSON 导入/导出（程序化备份）；参数卡政策明细支持**预览月份切换**（计算按每笔发放月份自动匹配年度）
- 数据已更新至 **2026 年度**（北京 36348/7270、上海 37731/7546、广深养老 27549 上限、江苏/重庆暂按 2025 标准执行等，更新于 2026-09-04）；广东最低工资自 2026-09-01 调整（广州 2680、深圳 2700，粤府函〔2026〕188号），广州公积金下限同步 2680，深圳失业保险下限/公积金下限同步 2700；广东省 2026 社保年度惯例 10 月公布，当前为沿用 2025 年度的过渡值
- ⚠️ 内置数值为参考值，请以当地社保部门公布为准；批量表格可带「城市」列（如 广州/深圳）按行内城市政策计算，也可整批选城市；无基数列时可勾选"按应发工资作基数"（自动按城市上下限 clamp）

### 📅 多月累计
- 采用12个月份网格布局，输入便捷
- 劳务 / 工资均支持税前→税后、税后→税前双向互算
- 支持指定计算年份，自动跳过空月份
- 劳务：支持"断月重置"（相邻月份中断超过1个月自动归零）、智能识别 2025年10月前后新旧政策
- 工资：按「工资参数」自动计算三险一金，结果含三险一金、专项附加、实发工资
- 支持导出计算结果为 CSV 文件

### 📁 批量计算
- 支持上传 CSV、Excel 文件批量处理
- **智能列映射**：自动识别表格列类型（姓名、月份、金额、身份证号、电话、银行卡号，工资模式额外支持**社保基数、公积金基数、公积金比例、专项附加扣除**）
- 支持手动调整列映射，可视化预览每列数据
- 支持"金额类型"选择：税前收入（累计预扣）或税后收入（反算）
- 工资模式下，行内基数/公积金比例/扣除列优先于全局「工资参数」，缺失时自动兜底并在结果中标注
- 兼容多种月份格式：2024-01、2024/01、2024年1月、202401、Excel日期序列号等
- 自动处理 GBK 和 UTF-8 编码，支持分批上传、累加计算

## 计税规则

### 劳务报酬（平台连续劳务）

**政策切换**：
- **2025年10月1日及之后**：适用新政策（连续劳务，累计预扣法）
- **2025年9月及之前**：适用旧政策（生产经营所得，不扣税）

**新政策：累计预扣法**（依据国家税务总局公告2018年第61号）：

| 累计应纳税所得额 | 税率 | 速算扣除数 |
|---------------|------|----------|
| ≤36,000 | 3% | 0 |
| ≤144,000 | 10% | 2,520 |
| ≤300,000 | 20% | 16,920 |
| ≤420,000 | 25% | 31,920 |
| ≤660,000 | 30% | 52,920 |
| ≤960,000 | 35% | 85,920 |
| >960,000 | 45% | 181,920 |

- **预扣收入额** = 每次劳务报酬收入 × 80%
- **累计预扣税额** = (累计预扣收入额 - 累计减除费用) × 适用税率 - 速算扣除数
- **累计减除费用** = 5,000元/月 × 累计月份数

### 工资薪金（累计预扣法）

依据国家税务总局公告2020年第13号，税率表与上表相同：

- **累计应纳税所得额** = 累计应发工资 − 5,000×月份数 − 累计三险一金（个人部分） − 累计专项附加扣除
- **本期预扣税额** = 累计应纳税额 − 累计已预扣（为负时取 0）
- **实发工资** = 应发工资 − 个人三险一金 − 个人所得税

**三险一金（个人部分，按城市政策分险种计算）**：

三险一金 = Σ [ clamp(社保基数, 该险种城市下限, 该险种城市上限) × 该险种个人比例 ]

- 内置城市政策库维护各险种的个人比例与基数上下限（如广东养老/失业按全省口径、医疗单独设限、公积金另有口径）
- 公积金基数默认跟随社保基数，可单独设置；比例按城市可选档位（5%~12%）择档
- 批量表格中三险一金一律按基数自动计算：行内基数列 > 全局基数 > 应发工资作基数（勾选后）> 0 并标注；公积金比例按 行内「公积金比例」列（填 5 = 5%，兼容 0.05/"5%"）> 「工资参数」择档；城市按 行内「城市」列 > 整批城市选择 > 「工资参数」城市

**示例**：月薪 10,000，自定义城市（养老 8%+医疗 2%+失业 0.5%+公积金 12%，无上下限），专项附加 1,000/月 →
三险一金 2,250；1月个税 = (10,000 − 5,000 − 2,250 − 1,000) × 3% = **52.50**；实发 = **7,697.50**
若参保广州（失业 0.2%、公积金 5% 档），同样月薪三险一金为 1,520，个税与实发随之不同——这正是分城市政策的意义

### 通用规则
- **跨年重置**：每年1月起，累计收入、累计已预扣税额、累计减除费用均归零重新起算
- **断月重置**（仅劳务）：开启后，相邻月份如果中断超过1个月，累计自动归零重新起算
- **同月多笔**：同一月份多笔收入合并计税，当月减除费用与三险一金只计一次

## 使用技术

- 纯前端实现，无需后端服务
- 支持 SheetJS (xlsx) 库处理 Excel 文件
- 响应式设计，适配桌面和移动端
- 暗色主题界面
- 内置控制台自检（`runSelfTests()`），页面加载时自动运行

## 本地使用

直接在浏览器中打开 `tax-calculator.html` 文件即可使用，无需安装任何依赖。

> 跨机拷贝或分发时，请将 `tax-calculator.html` 与 `tax-policy-data.js`（城市政策初始化数据）放在同一目录；缺少后者时工具仍可用（仅"自定义"城市），并会提示导入 Excel/JSON 政策数据。
