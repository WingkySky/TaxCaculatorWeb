# 个税计算器 · 劳务报酬 / 工资薪金

一款专业的在线个税计算工具，支持两大所得类型：

- **平台连续劳务报酬**（如直播打赏、外卖配送、网约车等）——支持**旧政策生产经营所得**和**新政策累计预扣法**自动切换
- **工资薪金**——按累计预扣法计算三险一金、专项附加扣除与个税，支持应发↔实发双向互算

两种类型均支持「多月累计」手工计算与「批量计算」表格上传。

## 功能特点

### 💰 所得类型切换
- 页面顶部一键切换「劳务报酬」/「工资薪金」，两个页签共用该选择
- 切换时自动联动说明文案、输入提示、断月开关显隐与批量列识别

### 📅 多月累计
- 采用12个月份网格布局，输入便捷
- 劳务 / 工资均支持税前→税后、税后→税前双向互算
- 支持指定计算年份，自动跳过空月份
- 劳务：支持"断月重置"（相邻月份中断超过1个月自动归零）、智能识别 2025年10月前后新旧政策
- 工资：按「工资参数」自动计算三险一金，结果含三险一金、专项附加、实发工资
- 支持导出计算结果为 CSV 文件

### 📁 批量计算
- 支持上传 CSV、Excel 文件批量处理
- **智能列映射**：自动识别表格列类型（姓名、月份、金额、身份证号、电话、银行卡号，工资模式额外支持**社保基数、公积金基数、三险一金、专项附加扣除**）
- 支持手动调整列映射，可视化预览每列数据
- 支持"金额类型"选择：税前收入（累计预扣）或税后收入（反算）
- 工资模式下，行内基数/扣除列优先于全局「工资参数」，缺失时自动兜底并在结果中标注
- 兼容多种月份格式：2024-01、2024/01、2024年1月、202401、Excel日期序列号等
- 自动处理 GBK 和 UTF-8 编码，支持分批上传、累加计算

## 计税规则

### 劳务报酬（平台连续劳务）

**政策切换**：
- **2025年10月1日及之后**：适用新政策（连续劳务，累计预扣法）
- **2025年9月及之前**：适用旧政策（生产经营所得，不扣税）

**新政策：累计预扣法**（依据国家税务总局公告2018年第61号）：

| 累计应纳税所得额 | 税率 | 速算扣除数 |
|---------------|------|----------|
| ≤36,000 | 3% | 0 |
| ≤144,000 | 10% | 2,520 |
| ≤300,000 | 20% | 16,920 |
| ≤420,000 | 25% | 31,920 |
| ≤660,000 | 30% | 52,920 |
| ≤960,000 | 35% | 85,920 |
| >960,000 | 45% | 181,920 |

- **预扣收入额** = 每次劳务报酬收入 × 80%
- **累计预扣税额** = (累计预扣收入额 - 累计减除费用) × 适用税率 - 速算扣除数
- **累计减除费用** = 5,000元/月 × 累计月份数

### 工资薪金（累计预扣法）

依据国家税务总局公告2020年第13号，税率表与上表相同：

- **累计应纳税所得额** = 累计应发工资 − 5,000×月份数 − 累计三险一金（个人部分） − 累计专项附加扣除
- **本期预扣税额** = 累计应纳税额 − 累计已预扣（为负时取 0）
- **实发工资** = 应发工资 − 个人三险一金 − 个人所得税

**三险一金（个人部分）**：

三险一金 = 社保基数 × (养老 + 医疗 + 失业比例) + 公积金基数 × 公积金比例

- 默认比例：养老 8%、医疗 2%、失业 0.5%、公积金 12%，可按城市调整
- 公积金基数默认跟随社保基数，可单独设置；支持选填基数上下限
- 批量表格中行内「三险一金」金额列 > 行内基数列×比例 > 全局「工资参数」

**示例**：月薪 10,000，社保/公积金基数 10,000（22.5%），专项附加 1,000/月 →
三险一金 2,250；1月个税 = (10,000 − 5,000 − 2,250 − 1,000) × 3% = **52.50**；实发 = **7,697.50**

### 通用规则
- **跨年重置**：每年1月起，累计收入、累计已预扣税额、累计减除费用均归零重新起算
- **断月重置**（仅劳务）：开启后，相邻月份如果中断超过1个月，累计自动归零重新起算
- **同月多笔**：同一月份多笔收入合并计税，当月减除费用与三险一金只计一次

## 使用技术

- 纯前端实现，无需后端服务
- 支持 SheetJS (xlsx) 库处理 Excel 文件
- 响应式设计，适配桌面和移动端
- 暗色主题界面
- 内置控制台自检（`runSelfTests()`），页面加载时自动运行

## 本地使用

直接在浏览器中打开 `tax-calculator.html` 文件即可使用，无需安装任何依赖。
