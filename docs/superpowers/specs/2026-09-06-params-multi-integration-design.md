# 工资参数 × 多月累计整合设计

日期：2026-09-06
状态：已与用户逐节确认（方案 A，经视觉伴侣草图选定）

## 背景与问题

工资薪金模式下，参数设置与计算被拆在两个页面，形成三段跳流程：顶栏切「工资薪金」→ 侧栏跳「工资参数」设城市/基数/专项附加 → 跳回「多月累计」填月计算，中途无参数与结果的联动预览。

连带问题：

1. **劳务模式下参数页是死页**。默认所得类型为劳务报酬，此时参数页仅剩一条警告横幅。
2. **批量页全局兜底选项出现太晚**。「整批城市」「无基数时按应发工资作基数」藏在上传文件后的预览区，上传前不可见。
3. **参数页标题名不副实**。「多月累计与批量计算共用」夸大了它在批量里的权重——批量中它只是行内列与整批设置之后的第三级兜底（page-batch.js: `rowCityKey || batchCityId || salaryParams.cityId`）。

## 目标

- 工资模式下，参数与计算同屏：切到工资薪金后无需跳页即可看到并修改全部参数。
- 消除劳务模式死页。
- 批量兜底设置前移到上传前可见，兜底链一处讲清。
- 计算引擎、导出器、政策库数据层、批量计税流水线零改动。

## 方案（A：参数卡内嵌）

### 1. 信息架构与路由

- 删除独立「工资参数」页：`#page-params` 区块、侧栏「工资参数」菜单项、路由 `'params'` 全部移除；侧栏「配置」组只剩「政策库」。
- 旧链接兼容：现有路由逻辑对未知 hash 回退到多月页，`#/params` 旧书签自然落到参数卡所在的多月页，无需额外处理。
- 劳务模式下参数卡与批量兜底盒整体隐藏，复用 `App.setIncomeType` 现有显隐机制。

### 2. 多月累计页 · 内嵌参数卡

- **位置**：页面卡片标题下方、计税方向切换上方。
- **结构**：卡片头（折叠箭头 + 「⚙ 工资参数」+ 实时摘要 chips：城市 · 社保基数 · 公积金档 · 附加月合计）+ 展开主体（原有全部内容：7 字段表单、专项附加分项面板、政策预览月份、险种明细表、「政策数据管理」按钮、缺数据文件提示）。
- **摘要**：随输入实时刷新（挂在 `readSalaryParams` 渲染时机上）；公积金比例显示当前生效值（城市择档显示档位，自定义城市显示手填值）；附加月合计在分项模式下取分项计算结果，否则取单一总额。
- **折叠**：点击卡片头切换；状态存 `localStorage`（key：`tc-params-card-collapsed`，'1'=收起）；无存储时的默认策略——社保基数为 0（从未设置）→ 展开，否则收起。
- **DOM 策略**：现有 `sp-*` DOM id 原样保留并整体搬入多月页，PageParams 模块逻辑不动；政策库页保存后的刷新钩子（`PageParams.onCityParamChange` / `renderSalaryItemsTable`）自动继续生效。
- 多月页输入提示文案改为「按上方「工资参数」计算」。

### 3. 批量页 · 兜底设置前移

- 上传区与格式说明之间新增「全局兜底设置」盒（仅工资模式显示）：整批参保城市下拉（默认「跟随工资参数」）+「无基数时按应发工资作基数」勾选 + 一行兜底链说明（行内列 > 整批设置 > 多月页工资参数；均缺记 0 并标注）。
- 上传后「选择计算方式」卡内原有同款控件移除，避免两处重复编辑；方向切换与断月重置保留。
- `TaxState.batchCityId` / `batchGrossAsBase` 语义不变；批量城市下拉初始化时填充，政策库增删城市后同步刷新（挂在 PageParams 城市联动时机上）。

### 4. 边界（不改的东西）

- `tax-engine.js` / `social-insurance.js` / `exporter.js` / 政策库数据层 / 批量解析与计税流水线不动。
- `salaryParams` 仍是同一份 `TaxState` 全局状态，仅编辑界面搬家。
- `PageParams` 从「页面模块」重新定位为「参数卡组件」，宿主换为多月页；对外接口不变。

### 5. 测试与验收

- 回归门：现有 94 项自检全绿（已确认自检脚本不依赖参数页 DOM）。
- 冒烟清单（file:// 与 http 各一遍，冒烟前重置 UI 状态）：
  1. file:// 双击打开 → 侧栏无「工资参数」项，「配置」组只剩政策库；
  2. 切「工资薪金」→ 多月页参数卡默认展开（未设基数）；
  3. 修改城市/基数 → 摘要 chips 实时更新、险种明细表联动；
  4. 填月计算 → 三险一金/个税/实发正确；
  5. 折叠卡片 → 刷新后仍记忆；清存储且基数已设 → 默认收起；
  6. 切回「劳务报酬」→ 参数卡与批量兜底盒消失；
  7. 批量页上传前可见兜底设置；上传后「选择计算方式」卡无重复控件；
  8. 政策库新增城市 → 批量城市下拉与参数卡城市下拉同步出现新城市；
  9. 访问 `#/params` → 落回多月页。
- 专项附加分项面板、政策预览月份切换、政策数据管理跳转在卡内功能不回退。
